## What's Available

### Android

| Variant | Description |
|---------|-------------|
| Universal APK | Works on all Android devices |
| ARM64 APK | Smaller size for modern 64-bit devices |
| ARM32 APK | For older 32-bit devices |
| x86_64 APK | For emulators and x86 devices |

### Windows

| Variant | Description |
|---------|-------------|
| Installer | Standard setup for Windows 10/11 |
| Portable | No install, extract and run |

### macOS

| Variant | Description |
|---------|-------------|
| DMG | Drag and drop to install |

### Linux

| Variant | Description |
|---------|-------------|
| DEB | Ubuntu, Debian, and derivatives |
| RPM | Fedora, RHEL, and derivatives |
| Flatpak | Universal Linux package |
| Portable | Extract and run, no install needed |

---

> On Android, you may need to enable "Install from unknown sources" in your device settings. On Windows, click "More info" then "Run anyway" if SmartScreen appears.
